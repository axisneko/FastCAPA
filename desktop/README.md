# FastCAPA — настольное приложение для Windows

Windows-приложение (`.exe`), которое открывает тот же интерфейс и тот же функционал,
что и сайт FastCAPA из корня этого репозитория: вход/регистрация, регистрация NCR,
реестр и карточка NCR, монитор, CAPA, наблюдение, уведомления.

Код сайта не изменяется: приложение запускает локальный веб-сервер на `127.0.0.1`
и показывает в окне те же самые страницы. Поэтому `localStorage`, переходы между
страницами и загрузка фото/голоса работают так же, как в браузере.

## Что внутри

| Файл | Назначение |
|---|---|
| `package.json` | зависимости и настройки сборки `.exe` (установщик + portable-версия) |
| `main.js` | главный процесс: локальный сервер, окно приложения, права на микрофон, внешние ссылки в браузере |
| `scripts/prepare-site.js` | копирует страницы, скрипты, стили и `img/` из корня репозитория в `desktop/site` перед запуском и сборкой |
| `site/` | создаётся автоматически, в репозиторий не коммитится |

## Что нужно установить

1. **Node.js 18 LTS или новее** — https://nodejs.org (при установке оставьте галочку «Add to PATH»).
2. Доступ в интернет для `npm install` (скачивается Electron, ~100 МБ).

Собирать `.exe` нужно на Windows: так сборка проходит без дополнительных настроек.

## Сборка .exe

Откройте PowerShell (или cmd) в папке `desktop` и выполните:

```powershell
npm install
npm run dist
```

Готовые файлы появятся в папке `desktop\dist`:

- `FastCAPA Setup 1.0.0.exe` — установщик (ярлык на рабочем столе и в меню «Пуск»);
- `FastCAPA-1.0.0-portable.exe` — версия без установки, можно запускать с флешки.

## Запуск без сборки (режим разработки)

```powershell
npm install
npm start
```

## Где хранятся данные

Данные (NCR, CAPA, пользователи, уведомлен��я) хранятся локально в профиле приложения
(`%APPDATA%\FastCAPA`), а не в браузере. Перенос данных между браузером и приложением
не выполняется. Если удалить приложение вместе с профилем, данные будут потеряны.

## Иконка приложения

По умолчанию используется стандартная иконка Electron. Чтобы поставить свою, положите
файл `icon.png` размером 256×256 в папку `desktop/build/` — сборщик подхватит его
автоматически и сконвертирует в формат `.ico`.

## Серверная часть

Репозиторий не содержит backend (папка `backend` отсутствует), поэтому приложение
работает в офлайн-режиме: справочники берутся из встроенного набора, а NCR
сохраняются в локальную очередь со статусом «в памяти».
